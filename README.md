# c--calculator
A simple calculator built using C
programming.

##features
-addition
-Subtraction
-Multiplication
-Division
-Division-by-zero handling
-multi calculations using a loop
-Exit option

##concept used
-Variables and data types
-Input and output
-if-else conditions
-loops
-Functions
-Basic arithmetic operators

##How to run
1.Compline the program:
gcc calculator.c-o calculator

2.Run the programm:
./calculator
